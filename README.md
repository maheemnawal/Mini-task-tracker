**Mini Task Tracker**

A menu-based Python application that allows users to add, view, complete, and delete tasks while saving task data in a JSON file.

**Features**

Add Tasks: Create tasks with a Pending status.

View Tasks: Display numbered tasks with their current status.

Complete Tasks: Mark tasks as Done.

Delete Tasks: Remove tasks from the list.

Save and Load: Store tasks in tasks.json and reload them when the program starts.

Error Handling: Handle empty titles, invalid menu choices, and invalid task numbers.
